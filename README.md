# 매출 데이터 분석 프로젝트

## 프로젝트 개요
매출 데이터를 분석하여 비즈니스 인사이트를 도출하는 프로젝트입니다.

## 분석 아이디어 브레인스토밍

### 1. 기본 통계 분석
- 총 매출액, 평균 매출액, 중간값
- 최대/최소 매출 거래
- 매출 표준편차 및 분산
- 매출 분포도 (히스토그램)

### 2. 시계열 분석
- 일별/주별/월별/분기별/연도별 매출 추이
- 매출 성장률 계산 (YoY, MoM, QoQ)
- 계절성 분석 (특정 시즌/월/요일에 매출 집중도)
- 이동평균선 (MA) 분석
- 매출 예측 (시계열 예측 모델: ARIMA, Prophet 등)

### 3. 제품/카테고리 분석
- 제품별 매출 순위
- 카테고리별 매출 비중
- 베스트셀러 vs 저조한 제품
- 제품별 성장률
- ABC 분석 (파레토 법칙: 상위 20% 제품이 80% 매출 차지)
- 제품 포트폴리오 분석

### 4. 고객 분석
- 고객별 매출 기여도 (VIP 고객 식별)
- 신규 vs 재구매 고객 비율
- 고객 생애 가치 (CLV) 계산
- 고객 세그먼테이션
- RFM 분석 (Recency, Frequency, Monetary)
- 고객 이탈 분석
- 고객당 평균 구매액 (AOV: Average Order Value)

### 5. 지역/채널 분석
- 지역별 매출 분포 및 순위
- 판매 채널별 매출 (온라인 vs 오프라인)
- 지점/매장별 성과 비교
- 지역별 선호 제품 분석

### 6. 가격 분석
- 가격대별 매출 분포
- 할인율에 따른 매출 변화
- 가격 탄력성 분석
- 평균 거래 단가 추이

### 7. 상관관계 및 패턴 분석
- 제품 간 교차 판매 분석 (함께 구매되는 제품)
- 마케팅 캠페인 효과 분석
- 날씨/이벤트와 매출 상관관계
- 재고 수준과 매출 관계

### 8. 성과 지표 (KPI)
- 매출 목표 대비 달성률
- 전년 동기 대비 성장률
- 평균 구매 주기
- 구매 전환율
- 재구매율

### 9. 시각화
- 매출 대시보드 제작
- 히트맵 (시간대별/요일별 매출)
- 트렌드 차트
- 파이 차트 (카테고리/지역 비중)
- 지도 시각화 (지역별 매출)
- 박스플롯 (이상치 탐지)

### 10. 이상치 및 품질 관리
- 비정상 거래 탐지
- 반품/환불 분석
- 데이터 품질 체크 (결측치, 중복, 이상값)

### 11. 예측 및 최적화
- 수요 예측
- 재고 최적화 추천
- 가격 최적화
- 매출 시뮬레이션

### 12. 보고서 생성
- 주간/월간 매출 리포트 자동화
- 경영진 요약 보고서
- 액션 아이템 도출
